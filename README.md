# Юрий Петрович Великолепный — царская летопись

Одностраничный интерактивный сайт — шуточная художественная хроника русского царя Юрия Петровича Великолепного.

## Что внутри
- Большая портретная обложка и стилизованная биография.
- Семь глав с семью оригинальными PNG-фотографиями из корня этого репозитория. Фотографии не изменены.
- Три увлечения государя: любимая еда, красивые женщины и волшебная скрижаль с «Рэйд Шаров Легендс».
- Интерактивная фотогалерея с просмотром в полном размере, стрелками, Esc и жестом нажатия.
- Генератор смешных царских указов с копированием.
- Адаптивный дизайн для телефона, планшета и компьютера. Без сборки и npm.

## Просмотр
Откройте файл `index.html` в браузере. Все изображения берутся из корня этого репозитория.

**Публикация через GitHub Pages:** Settings → Pages → Build and deployment → Deploy from a branch → выберите `main` / `/(root)` → Save. После активации ожидаемый адрес:
https://yalacom.github.io/iuratsary/

## Файлы
- `index.html` — семантическая страница и контент.
- `styles.css` — визуальная система.
- `script.js` — главы, галерея, указы, взаимодействия.
- `favicon.svg` — векторная иконка короны.
- `DESIGN_SYSTEM.md` — дизайн-токены и UX-решения.

## Важно
Сюжет является **шуточной вымышленной летописью**, а не исторической биографией.
Семь оригинальных изображений взяты из архива репозитория. Сценарные названия глав художественные, не являются доказанной идентификацией конкретных фотосцен.
